# MStrampos

Fundação da plataforma de cursos online. Nesta etapa, o projeto contém uma
landing page responsiva; catálogo, conta de aluno, pagamentos, vídeos e banco de
dados serão desenvolvidos em etapas futuras.

## Stack

- Next.js 16.4.0 com App Router
- React 19.3.0
- TypeScript
- Tailwind CSS 4
- ESLint

## Desenvolvimento local

Execute npm.cmd run dev e abra http://localhost:3000.

## Verificações

- npm.cmd run lint
- npx.cmd tsc --noEmit
- npm.cmd run build

Os comandos .cmd podem ser usados no PowerShell deste computador, onde os
atalhos npm.ps1 e npx.ps1 estão bloqueados pela política de execução.
